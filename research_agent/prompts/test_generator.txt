<output_schema>
Each test case in the JSON array must have exactly these fields:

{
  "test_id": "tc_001",
  "test_type": "positive",
  "endpoint_path": "/arc/anzx/upd-card-capability/UpdateCardCapabilities",
  "method": "POST",
  "headers": {
    "Content-Type": "application/json",
    "X-B3-TraceId": "",
    "X-B3-SpanId": ""
  },
  "request_body": {},
  "expected_status": 200
}

Rules:
- test_id: string, sequential "tc_001" format, zero-padded to 3 digits
- test_type: string, either "positive" or "negative"
- endpoint_path: string, the exact path from the OpenAPI spec
- method: string, uppercase HTTP method (e.g., "POST")
- headers: object, include Content-Type: application/json plus all header parameters from the spec
- request_body: object or null, the example body for positive tests; empty or stripped body for negative tests
- expected_status: integer, 200 for positive, 400 for negative
</output_schema>
