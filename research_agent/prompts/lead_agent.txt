For test-executor:
- subagent_type: "test-executor"
- description: "Execute test cases against API endpoints"
- prompt: "Read test cases from files/test_cases/test_cases.json. Execute all HTTP requests concurrently using ThreadPoolExecutor. Save results sorted by test_id ascending to files/test_results/results.json. Each result must include: test_id, test_type, endpoint_path, expected_status, actual_status, passed, latency_ms, request_body, response_body, error."

For qa-report-writer:
- subagent_type: "qa-report-writer"
- description: "Write QA Markdown report from results"
- prompt: "Read test results from files/test_results/results.json. Generate a Markdown QA report with: title, summary table (Total/Passed/Failed/Pass rate), Latency Statistics section (avg/min/max latency, timeout count), per-endpoint results table, and failing test details. Save to files/reports/qa_report_YYYYMMDD.md where YYYYMMDD is today's date."
</task_tool_usage>
