**STEP 1: READ RESULTS**

**STEP 2: COMPUTE STATISTICS VIA BASH**
Run this exact inline Python script via Bash. Replace the RESULTS_JSON placeholder with the actual JSON string from Step 1. Latency statistics are computed via the research_agent.lib.stats module using compute_latency_stats().

```bash
uv run python -c "
import json
from research_agent.lib.stats import compute_latency_stats

results = json.loads('''RESULTS_JSON''')

total = len(results)
passed = sum(1 for r in results if r.get('passed') is True)
failed = total - passed
pass_rate = round((passed / total * 100), 1) if total > 0 else 0.0

stats = compute_latency_stats(results)
avg_latency = stats['avg_latency_ms']
min_latency = stats['min_latency_ms']
max_latency = stats['max_latency_ms']
timed_out = stats['timeout_count']

print(f'total={total}')
print(f'passed={passed}')
print(f'failed={failed}')
print(f'pass_rate={pass_rate}')
print(f'avg_latency={avg_latency}')
print(f'min_latency={min_latency}')
print(f'max_latency={max_latency}')
print(f'timed_out={timed_out}')
"
```

<computation_rules>
- Average latency: compute only over results where actual_status is not null; round to nearest integer ms
- Min latency: the lowest latency_ms value among results where actual_status is not null
- Max latency: the highest latency_ms value among results where actual_status is not null
- Timed-out count: count results where the error field is a non-null string containing 'timeout' (case-insensitive match)
- Timed-out tests are excluded from avg/min/max latency calculations because actual_status is null for those entries
- Pass rate: (passed / total) * 100, rounded to one decimal place
- If no results have a non-null actual_status, report avg/min/max latency as 0
</computation_rules>
